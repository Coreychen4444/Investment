# 研究裁决账本（公开版）

这个系统有一条硬规矩：**任何会动钱的规则改动（入场、确认口径、止损、sizing），先用一次预注册的回测定价，再决定接不接线。**
本页汇总 2026-07 到 2026-09 跑过的主要研究：问的是什么、按什么判据、结论是采纳 / 不采纳 / 未裁决、为什么。
最有信息量的往往是「不采纳」那一栏——大多数听起来很有道理的改法，在数据里要么没有增益，要么只是把风险换了个形状。
每条结论都带复测条件（多数是 +12 个月数据），不是永久真理。

> [!info] 研究账本镜像
> 本页是作者私有交易系统里「裁决账本」与各份预注册设计稿的公开摘要（原文住私有仓 `quant/research/`）。ticker 一律替换为 `STOCK_*` 占位符（本页基本不点名个股）；文中 `quant/...` 与 `fastlane_k` 之类的名字指私有系统里的代码与回测脚本，保留作出处，公开读者读语义即可。「用户」= 系统所有者与最终裁决人，「agent」= AI 研究助理。数字一律是 % / pp / bp / R / N，不含任何账户金额。

> [!note]- 术语速查
> - **N** = ATR20（20 日平均真实波幅）。口头说「0.5N」必须带基准和方向：gate 上方 / gate 下方 / 收盘下方是三件事。
> - **R** = 收益 ÷ 入场时的止损距离；**pp** = 百分点；**bp** = 基点，近期研究常用「按 live sizing 折算后的每笔 / 每情形 NAV bp」作主度量（R 会被极近的止损撑爆）。
> - **gate** = 状态转移线：市场反复在那个价上做过决定的地方（pivot 簇、供给簇、旧高、破位起点）。收盘站上 ×N 日 + 量腿过 → 授予仓位上限（cap）。
> - **RelVR** = 个股量比 ÷ max(基准量比, 0.4)，基准：半导体用 SMH，其余用 QQQ。
> - **T20 / T60** = 自起算点 20 / 60 个交易日的终点视界。**Kish n** = 按月或按票聚类后的有效独立样本数，闸门常设 ≥30。**CI90** = 按票 / 按月 / 按周 cluster bootstrap 的 90% 置信区间。
> - **止损率 / whipsaw** = 被止损的比例 / 止损后在窗口内又涨回成本的比例。**覆盖率** = 在视界内拿到入场资格的比例。
> - **止跌低 L** = 抄底模式的止损锚（下影线低点）。**P_rw** = 零参数随机游走下「20 根内先收盘越前高、后才收破止跌低」的概率。

## 研究纪律

1. **先锁后跑。** 假设、臂、判据（含守卫阈值）、样本、终点、随机种子在看到任何结果数字之前写死，通常先单独 commit 进 git（「判据先于数字」）。后来这条进了代码：守卫阈值没锁时回测脚本拒跑；样本外判定前写 LOCK 文件并记 sha256。开跑前才发现的口径漏洞写成「运行前修订」公开申报；跑完才加的格一律标「事后探索，不进裁决」。
2. **样本内探索 → 锁文件 → 样本外一次性判定。** 近期流程是在 2020–2026 窗口里探索形状，锁定判据后在从没碰过的 2010–2019（或 2010–2023）窗口里只跑一次。样本外吃掉样本内的「显著」是常态；一段历史窗用过就不能再用，只剩前向样本。
3. **配对、聚类、有效样本。** 所有臂跑同一批 episode 取配对差；CI 按票 / 按月 / 按周 cluster；Kish n <30 的格只报不裁。市场层标签同日共享，有效样本 = 状态段数或事件数，不是信号数。
4. **回归门。** 新 harness 必须先逐位复现上一份裁决的对照臂；复现不了就是引擎或数据变了，先查清再读结果。研究层常量故意冻结在裁决当时的 live 值，保证旧裁决永远可复现。
5. **「裁决不需要·定价值得跑」。** 风险偏好类参数（单票 40% 名义上限、组合 gross 110%、熔断线、gate 风险预算）没有反事实可以裁决，由用户直接定（fiat）；但每个都附价签（例：gross 110% 的代价 −0.17pp；名义 5% at-risk 打满 ≈ 实证 7%）。
6. **「不采纳」有三种强度，不能互换引用：** 判据失败（没证明有用）/ 平手保留现行（没有更好）/ 部分通过（风险降了，R 没赢）。「未裁决」（样本不足）又是第四种，它什么都没否掉。
7. **判据全过 ≠ 采纳。** 每条判据只给自己的 CI，不给「候选 − 现行」的差。gate 画法换 HVN 那轮四判据全过，配对差却四格全负。
8. **人裁可以知情覆盖机械裁决，但要记账。** 例：量腿对齐日机械读数是维持，用户知情裁放宽——判据不改、代价和撤回条件写在账上。反方向也有：open-risk 口径用户选了与 agent 推荐相反的「名义」口径；熔断「直接清仓」是带着已知反证（反事实读出清仓在卖底）裁的——两者都把证据和复核时点写在账上。
9. **判据的选择本身可能是胜负手，必须在看数据前锁。** 量腿 1.2→1.1 那轮，期望判据选了非劣效（边际 0.10pp）而不是前三轮的 superiority；读数余量只有 0.0055pp，若沿用 superiority 这格就不过。
10. **账本自身的卫生。** grep 到符号推不出裁决方向：live 参数 `fastlane_k` 的名字来自一个被否的概念，数值来自同一天另一份被采纳的研究。同一个词（快车道、0.5N、1.2、板块、cap）在不同文档指不同东西，引用必须带「哪份文档 / 哪一层 / 哪个自由度」。
11. **接线 ≠ 改常量。** 判据住在卡片字段里时，只改代码常量行为一点不变；采纳后要迁数据、改规则文本，并加一条「未迁的卡按旧值拦」的测试钉住。

## 三条研究链：一个问题是怎么被问完的

单份裁决容易被断章取义；多数问题是几轮连着问完的，结论要成串读。

**量腿（修复 gate 的成交量确认），四轮**
1. 2026-08-06 换尺：绝对量比 → RelVR。顺带证明整条拆掉止损率 +6.4pp，所以腿保留、只换尺。
2. 2026-09-08 换钟：累计量替代完成日量比 → 止损率 +3.07pp，否。
3. 2026-09-08 对齐日：连续站上期间任一日过即算 → 机械维持，用户知情裁放宽。
4. 2026-09-09 阈值：1.2 → 1.1，剂量-反应显示没有膝点。

合读：这个池里修复 gate 的确认口径已近最优，任何方向的放松都是覆盖换止损率、期望不动；再动它只走 +12 个月复测窗，不再单点立项。

**快车道（「早一天」），一个词承载一次采纳、三次否决**
1. 2026-07-31 箱体顶突破靠单日放量提前一天 → 否。
2. 2026-08-07 同一天两份：修复 gate 上「全额提前」否；「分档提前（k = 0.5）」采纳。
3. 2026-08-08 按 gate 结构身份分级 → 四类全否；对照臂还反咬一口：分档那份的对照同时变了「执行结构」和「时点」两个自由度，「早一天」其实从没被单独验过。
4. 2026-08-08 单自由度重测：早一天 R 显著为正，却被止损次数守卫否掉。
5. 2026-08-09 守卫本身重新预注册（改量代价不量次数）→ 重判支持；分类判别式接进 live，非修复类一律 ×2。

合读：单独引任何一份都会得到反向答案。证据完备的结论是「修复路径专属、分档执行、代价守卫下成立」。

**抄底（🔁 模式），从一条信号到一套几何**
1. 2026-09-11 反转探针（新低 + 一根阳线）作为期权的第二入场类加进来；次日回放发现它对用户给的四个抄底例子一个都没授权。
2. 2026-09-12 信号换成最朴素的价格行为（次日未新低 / 长下影，止损 = 止跌低），定价显示：早入场换来的是高止损率，不是更高期望。
3. 2026-09-14 三件同日：有效期改 ATR 上限、底部确认概率落到随机游走几何、一轮真实下跌立前向验证。
4. 2026-09-15 砸回重确认 → 样本外否。2026-09-23 补一段下跌门。2026-09-24 大盘状态不能帮它择时。

合读：每一步都是一个直觉判据（多数来自用户）先定价、再改码；前提对一半的情况最常见（「年龄无效」对，「贴着底再试」反了；「维度越多反转率越高」在原始数据里成立，控制位置后消失，「维度越多越不会被扫」从一开始就不成立）。

## 十条耐久教训

1. **gate 是保险，不是 alpha。** 不建止损时 gate 只是延迟器：触发率 97–100%，六格 T+60 全跑输 2.3–3.5pp，p10 不变。建了止损之后它显著压低止损率（−8~−30pp）、改善左尾（p10 +0.3~+4.6pp），代价约 1pp/episode 的期望。所以它只管「破位后重进」的授权，新开仓不等 gate；stop 放在 gate 下方 0.5N，而不是 gate 本体（那是 whipsaw 机器）。
2. **进出场时点决定风险形状，不决定 edge。** 同一个形状独立出现了至少五次：抄底每多等一天确认，止损率 49→41→34%，期望 CI 全重叠；有效期里贴着止跌低入场止损率 70–76%，每笔 NAV 反而最低；砸回止跌低时等再止跌，止损率 74→56% 但每情形 NAV −15bp；道氏终止提前离场 ΔR −0.030；⭐箱顶样本内「止损少、R 高」到样本外持有收益无差。改时点 = 在止损率与覆盖率之间做交换，不是加钱。
3. **量比阈值 1.2 是一个从没测过的约定，而且没有膝点。** RelVR 六桶止损率 54.2–57.4%，不单调；但把量腿整条拆掉止损率 +4.19pp——保护来自「等」而不是读数，量腿是钟不是筛子。曲线不对称：放松到 1.1 非劣效，收紧到 1.5 显著亏 −0.48pp [−0.82,−0.17]。用累计量替代完成日量腿（量的钟）止损率 +3.07pp，因为它把「等」拆掉了。
4. **底部确认概率 ≈ 零参数随机游走的位置几何。** 在 2010–19 与 2020–26 两个相位、13,463 个信号上，P_rw 十分位全单调，平均只低估 2.5 / 3.7pp。地标收敛、个股独立、放量、超卖、背离、收上止跌日高的原始优势（+5~+17pp）几乎全是「命中组离前高更近」；控制位置后没有一个事实在两个相位同号地抬高概率。概率与赔率是同一件几何（离止损越近，概率越低、赔率越高），所以它只能看，不能用来排序或定仓。
5. **样本外会吃掉样本内的「显著」。** ⭐箱顶突破样本内止损率 −4pp、R +0.25、策略收益 +1.1pp，样本外差值 [−0.58,+0.54]pp；底部证据里「个股独立」的 OR 1.06 → 0.74 反号；砸回重确认样本内 +10bp、样本外 −15bp。根源是分叉路径：定义是看过样本内之后选的。所以只能「样本内探索 → 锁文件 → 样本外一次」，窗口用完只剩前向样本。
6. **退出参数已经局部最优，杠杆在执行率。** 账户反事实里规则全栈保住峰值浮盈 ~27%，实际执行几乎全数回吐；两个「更稳」的软化（破位缓冲、严格重进门）都净负。之后「在 +50% 之前给浮盈上保险」又以道氏提前离场、N 计价提前武装两种形式被否。于是退出栈不设 override：告警成立当日执行，见 [[trend-exit-system]]。
7. **数据里没有稳定的风险板块，组合风险只剩总量尺。** 聚类的分离度能过（sep 0.233），稳定性过不了（ARI ≤0.15，簇数少时为负）。冲击预算只留总额 15% NAV，并在文档里写明这套东西的实质：单票 40% + 组合波动率目标 + gross 110%，不是逐仓风险模型。
8. **大盘状态不是择时工具。** 「震荡 vs 单边」对两种模式的区分两个窗口都不成立（突破臂样本外甚至方向相反）；FOMC 后大盘表态次日提前进，131 次定期会议上只多 +1.6bp；CPI / 非农提前进的约 20bp 来自「早进」本身，大盘没表态的事件同样好。大盘只作整体参考，不进排序、不进授权。
9. **分数越高不等于越好：连续评分会买在 salience 峰值。** 趋势强度分高带 meanR 反而不升、止损率 55→61%；底部八轴计票的 mean R 随分递减（高分买的是离止跌低更远）；强突破的分档增益只在 0.5–1.0N 带，>1.0N 平局。「确认越多越该下重注」在 T60 口径下反复被否。
10. **事件风险集中在反应当天，不在之前一周。** 财报前 5 日中位波动 = 基线的 0.99–1.05×，「财报前一周缩仓」找不到依据；只有反应日 T+0 需要缩仓，且小样本票的冲击估计要向池级收缩（λ = n/(n+10)）。同一个道理的另一面：深跌不等于便宜——期权里深跌反转的期望 ≈0，真正分辨好坏的是 IV / HV 分位（<40 胜率 62%，≥80 期望为负）。
