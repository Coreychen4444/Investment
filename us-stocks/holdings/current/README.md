# Current Holdings Notes

每个持仓 / 候选一张「卡」（用 `_EXAMPLE_.md` 当模板），不是券商导出，而是结构与判断的快照：

- **结构层（唯一授权来源）**：z1 / z2 / trim / no_chase / stop，current regime（cap 0 或 40% NAV），下一个 gate
- **判断层（[FYI]）**：thesis 框架 —— 假设、驱动、空头与证伪、估值交叉验证、下一催化剂
- **退出**：交给系统的钟（stop / 棘轮 / 趋势死亡线），不在卡上写「看情况」

## How to use
- 一只标的一个 `.md`，卡片过期（`valid_until`、突破 trim、收盘破 z2 下沿、单日 >2×ATR 异动、自家财报）先重画再判断
- 禁止用过期的卡硬拦交易，也禁止只凭 K 线不看宏观归因就改线
- 系统全貌见 [[system-overview|系统总览]]
