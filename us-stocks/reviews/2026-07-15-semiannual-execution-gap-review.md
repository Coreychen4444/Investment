# Review — 半年复盘：执行缺口 + 心态×结构错配（2026-07-15）

## Summary
半年交易复盘。原始自我诊断："最大问题是不懂止盈，性格使然，不适合做交易。"数据验证后，诊断被修正为：**不是知识缺口（"不懂"），是执行缺口 + 盈利回收进杠杆；不是性格宿命，是价值心态 × 趋势结构错配。**

这次复盘产出了一条新的 canonical 规则：[[mindset-structure-pairing|心态×结构配对]]。

## 数据（全部经账本验证，非记忆叙述）
- 账户 NAV：峰值（6/23）→ 三周后（7/15）**-49.3%**；同期 QQQ +3.7%、SPY +3.6% → **个人回撤，非市场回撤**（板块回调 × 杠杆结构放大成腰斩）
- 峰值→腰斩期间**主动卖出 0 笔**；7 月唯一成交 = 7/2 STOCK_X LEAPS 被券商风险等级强平（-$2,295）
- ~8/10 标的曾有可观浮盈（两大核心至今 +149% / +75% 在手；被强平标的曾 +100%；多只已落袋）
- 全周期 realized + unrealized 仍为正——"回吐了全部利润"是**峰值锚定记账**，锚定本身即病灶之一

## What went wrong（process 维度，两条链）
1. **Winner-side 执行缺口（repeat pattern，非 variance）**：G-01（+100% 强制部分止盈）触发执行率 **0/2**（同标的同错误间隔六周）；每张期权 lot 的 target_exit 全部写在案、全部未执行。复盘当日仍有一张 LEAPS 的 stop 连破 8 日未处理——pattern 是现在进行时，不是历史。
2. **盈利即刻回收进更高杠杆（house money 加码）**：峰值 ±2 天内连做三笔——lower-high 加仓（early_risky flag 在案仍执行）、DITM roll-up 换 38% OTM、在 IV 88-94% 极值买新 OTM LEAPS（系统预警在案仍买）——cash 全程为负。**暴露度随赢利单调上升 = 数学上保证顶部满杠杆**，-49.3% 是该函数的必然输出，不是运气。

## 诊断校准（三处，决定修复方向）
1. **"贪婪"是道德词，不是机制词。** 道德归因暗示意志力修复，而意志力已实测失败两次。机制词——实现厌恶（平仓 = 宣判叙事结束）、不对称后悔厌恶（怕卖飞 > 怕回吐）、house money（浮盈当筹码不当资产）、峰值锚定（峰值成为"我的钱"）——才指向机械化修复。**忏悔的复发率是 100%，结构的复发率才可控。**
2. **"过度相信研究"不准确。** 选股 8/10 对，研究没错；错在让**终点判断**（EPS×PE 去哪）担保**路径暴露**（回撤深度 / 拥挤出清 / IV 坍缩 / 资金久期）。被强平标的的 thesis 至今未证伪、仓位先死 = **资金久期 < thesis 久期**的直接后果。
3. **"其实只是趋势交易者"的身份羞耻放错地方。** 真问题是**交叉配对**：价值投资的"不卖" × 趋势交易的杠杆结构 = 各取两流派的风险、各丢两流派的保护。内证（同账户、同月、同人）：STOCK_Y 底仓（价值配对：正股+锁死+无到期+无杠杆）+149% 全程存活；STOCK_X LEAPS（错配）+100% → 强平。**半年亏的是错配税，不是选股税。**

## What went right
- 选股 / thesis 层面持续有效（~8/10 曾浮盈，核心持仓至今大幅为正）
- 底仓锁死规则被严格执行——半年最佳决策恰恰来自"结构对了的价值式持有"
- 复盘诚实：数据全部对账，未粉饰成"运气不好"；接受执行缺口定性
- 复盘时点 caveat 被当面记录：复盘发生在触底次日全 book 反弹日——自我判决的情绪时点与峰值欣快是同一机制（P&L 代言）。"不适合交易"按后悔句式处理，不采纳为结论

## Rules extracted
1. **持有心态的资格由结构授予，不由 conviction 授予**（→ [[mindset-structure-pairing|心态×结构配对]] canonical，含配对表 + 资格自检 5 条）
2. **趋势配对 book 上禁用"基本面没坏就拿着"**——资金久期 < thesis 久期时没有说这话的资格
3. **浮盈期加杠杆（roll-up / 升 strike / 加新 LEAPS）前必答："下桌还是重新押上？"**（house money 检测）
4. **敬畏市场的唯一可执行形式 = 清醒时预先交出的结构**（预挂单 / 告警执行承诺 / 书面 override 流程）——欣快期里感受不到敬畏，情绪版敬畏不存在
5. **修复判据单一化：exit 告警执行率**（当日执行或书面 override 二选一；月度 override ≥2 = 系统性问题）

## System produced
「**心态×结构配对规则**」：价值配对（正股/零杠杆/无到期/size 扛得住 -50%）允许价值式持有；趋势配对（期权/margin）退出权归机械系统。**两种配对都能活，只有交叉配对必死。** 详见 [[mindset-structure-pairing]]。
