# Review — stop 破了 ×1 立即清仓：override 三用三付费，退出栈 override 条款整条废止（2026-08-22）

## Summary
8 月中旬两周内，退出栈的「书面 override」（破位后写一段理由、多看一天再裁）被用了三次：一张 LEAPS 把已触发的止损线往下挪，新线被破后又迟到 3 个交易日才走；两只正股破 stop 后「看一天」。**三次全部付费。** 同一天破 stop、当天盘后就执行的那一只，**零附加税**。其中「看一天」买回来的那个交易日，第二天盘后就被公司公告的增发砸穿。

用户 8/22 裁决：

> **「stop 破了 ×1 立即清仓退出，不能再心存侥幸。」**
> 同日补裁：**「一并退役，棘轮趋势线也不留 override。」**

结果：退出栈（卡片 stop / 棘轮地板 / 趋势死亡线 / G-01）的 override 条款**整条废止**。退出侧唯一合法的「不卖」= 告警判据本身未成立（收盘口径、×N 日），不是「理由更好」。被废止的正是 [[2026-07-15-semiannual-execution-gap-review|7/15 半年复盘]]立下的「当日执行或书面 override 二选一，月度 ≥2 次 = 系统性问题」——而 override 从来没有等到月度 review 才显形，每一次都是当期损失。

## 时间线
- **8/7 + 8/10**：STOCK_GO LEAPS 的标的连续 2 日收盘跌破卡片线，8/10 简报首报 🚨 STOP。
- **8/11**：书面 override——退出线下移到一个多维收敛的更低 pivot 簇，外加一条 DTE 时间止损，写明「触发即平仓、不再重新对话」。agent 保留意见在案：「这是止损下移」；「告警消失是因为线被移了，不是因为风险消失了」。
- **8/12**：下移后的新线也被确认跌破。**8/17** 才平仓 = 迟到 3 个交易日。
- **8/19 收盘**：三只正股同日首次收破卡片 stop（×1 日口径），收盘距 stop：STOCK_Z −2.1% / STOCK_W −5.1% / STOCK_IN −1.2%。postclose 降级机 10 分钟内换了图，旧 stop 被抹掉——**全链零告警**。
- **8/19 盘后**：STOCK_W 在收盘约 2 小时后盘后全平 = 当日执行。这是退出执行史上第一个准时止损（此前 0/2，外加 STOCK_GO 迟到 3 日）。
- **8/20 盘前**：用户口头「其他两个看多一天」，当场书面化为 override：裁决边界 = 8/20 收盘，参照线 = 降级前的旧 stop；收回 = 持有，仍在下方 = 平仓。当时 STOCK_Z 盘后价恰在旧 stop 上方 +0.06%，「看一天」看起来几乎免费。`exit_overdue` 不因 override 消音，照常点名到动作为止。
- **8/20 收盘**：STOCK_Z 收在旧 stop 上方 +3.4%（whipsaw 收回形状）→ 持有。STOCK_IN 仍在下方 → 边界原文「执行平仓」，实际盘后只卖了 48%，其余无书面理由继续持有。
- **8/21**：STOCK_IN 残仓盘中清掉。STOCK_Z 常规收盘 −3.3%，当前（降级后）卡上没有任何线被破，**系统的钟说「持有」**。收盘后，公司盘后公告新一轮 ATM 增发（此前已有同类先例）；用户在公告后半小时内以整数限价全平。其后盘后价又跌到出价下方约 −6.5%。
- **8/22**：裁决 + 同日补裁，当天全部落地（见「规则落地」）。

## 算账：三次 override，三次付费
| 案例 | 准时执行的世界 | 实际 | 附加成本 |
|---|---|---|---|
| STOCK_Z「看一天」 | 8/19 盘后出，约 −15.4% | 8/21 增发公告后出，−18.7% | **−3.3pp（≈ −$98）** |
| STOCK_IN「看一天」 | 8/19 盘后出，约 −7.0% | 8/20 出 48% + 8/21 出余下，−9.6% | **−2.6pp（≈ −$76）** |
| STOCK_GO LEAPS（下移 + 迟 3 日） | 新线确认当日出 | 迟 3 个交易日出 | **≈ −$725** |
| STOCK_W 准时执行（对照组） | 8/19 盘后出 | 8/19 盘后出 | **0** |

两只正股的附加税合计不到 $200，不大。大的是**暴露**：增发砸的正是 override 买回来的那一天——8/20 那个「whipsaw 收回」，一天后就是废纸。7/17 的退出规则反事实回测早已否决「破位确认缓冲」这类直觉上更稳的变体（终值更差）；这次只是 live 又交了一遍同样的学费。

## What went wrong
1. **override 条款本身就是侥幸的合法出口。** 告警文案写着「当日执行或书面 override」= 在触发时刻给人递台阶。而触发时刻恰恰是人最不可信的时刻（[[trend-exit-system]] §6.2「触发时刻的你不可信任」）。
2. **「看一天」是拿一个已确认的破位去换一个未知的明天。** ×1 口径的破位已经确认过一次；再看一天不是多一份信息，而是多一天暴露——这一天里发生什么（这次是盘后增发）都不在卡上。
3. **override 会被部分执行、会被下移。** STOCK_IN 的边界写着「执行平仓」却只执行了 48%；STOCK_GO 把已触发的线往下挪，新线被破后又迟到 3 天。书面理由没有约束力，只有形式。
4. **系统侧：评估排在转移之后。** 8/19 降级机先换图、抹掉旧 stop，退出评估后跑，于是破位当晚全链零告警。STOCK_W 的准时执行靠的是人自己看见，不是钟响。
5. **画卡缺口（归 agent）。** STOCK_Z 此前已有增发先例，卡上的 `key_risk` / `invalid_if` 却没有「增发窗口」预承诺，于是 8/21 的退出只能落在「钟外」。

## What went right
- **STOCK_W 当日执行**：卡上自己写的 `invalid_if` 如约执行，盘后能成交就当晚成交，零附加税——这正是 §6.1 要的形状。
- **8/21 盘后防守退出（A-）**：一手公告信息、半小时内行动、早于社交媒体上的群体反应约 1 小时；比例正确（这张卡已降级为 cap 0，结构自己写着「突破失败」：一串 lower high + 收盘跌破最近摆动低点，没有值得留的东西）；单笔整价限价一次成交。
- **收盘口径没被破坏**：8/21 盘后价短暂穿过当前 stop，盘后穿越不计数；8/20 依旧「盘中不裁，收盘裁」。
- **机械追踪不消音**：override 期间 `exit_overdue` 与 ladder ⬇ 照常逐日点名——STOCK_GO 迟到 3 日的形状，正是消音会重演的形状。

### 钟外防守 vs 4 月的盘后追涨：规则罚的是方向，不是时段
8/21 是一次 after-hours catalyst **cut**：判断退出，落在系统的钟之外，扣分项明确（钟外 + 卡上无预承诺），但方向是防守。4 月有过一笔 after-hours catalyst **chase**：盘后看到催化剂就开新仓，评 C，并催生了「催化剂 ≠ 确认」等一组入场规则。同一个时段，两个方向，两个分数。**之后的结果也不改 8/21 的分**——「错 + 好 = D」陷阱只管进攻向 / 持有向，防守向不适用。

## 评分（process × outcome）
| 笔 | process | outcome | 分 |
|---|---|---|---|
| STOCK_W 8/19 止损 | 当日执行 ✓（入场侧另有规则外，episode 仍是 C） | 小亏 | exit 侧 = 正样本 |
| STOCK_Z 8/20 override | 边界当日立、收盘裁、依据真实；但 ×1 破位已确认过一次，override 消费纪律信用 | 次日被增发砸穿 | **B** |
| STOCK_IN 8/20 override | 边界说平仓，只执行 48%，残仓无书面理由 | 多亏 2.6pp | 未单独落分（按新规 = C 起步） |
| STOCK_GO LEAPS | 入场冲动单 + 退出线下移 + 迟到 3 日 | −60% | **C** |
| STOCK_Z 8/21 盘后全平 | 一手信息、比例对、执行干净；钟外 + 卡上无预承诺 | 出在盘后急跌之前 | **A-** |

裁决**向前有效**：8/20 那个 B 不追改。之后 8/24 STOCK_O 旧 stop 被破，当晚盘后全平，D+0 机械评分 **A**——新口径下的正样本。

## 规则落地
1. **[[trend-exit-system]] §6.1 改写**：卡片 stop 按 `stop_level_days` 收盘确认（含 `invalid_if` 同线）= 当日清仓（盘后可成交即当晚），**无 override 路径**；未执行 = 规则外，评 C 起步；brief 的 `exit_overdue` 逐日点名到动作为止。
2. **同日补裁：棘轮地板 / 趋势死亡线 / G-01 一视同仁**。旧「书面 override 进 journal，月度 ≥2 次 = 系统性问题」条款整条废止。
3. **告警不再递台阶**：brief 的 🚨 STOP 与 `exit_overdue`、`exit_guard` 的告警文案、gate 阶梯报告、定时任务 prompt，全部删掉「或书面 override」这一步。
4. **[[trading-discipline]] 新增行为检测「破 stop 后心存侥幸」**：出现「再看一天 / 盘后收回来了 / 基本面没坏」→ agent 逐字引用裁决原文，不提供「看一天」选项，不替人起草 override 理由。
5. **评估先于转移**（8/19 当轮修）：postclose 先跑 brief（退出评估），再跑 regime（降级换图）；加 `exit_overdue` 追踪与 ladder ⬇ 断层标记。旧 stop 被新图改写之前，破位必须先被看见。
6. **画卡**：增发节律整理成因子卡，只进 `key_risk` / `update_trigger`（v3 FYI 层，不驱动授权）；卡上有了预承诺，同类退出就回到钟内。

## Lessons
1. **「宁可错过，不可失序」在退出侧的形状 = 不给明天。** 被确认的破位不是一个待讨论的观点。
2. **override 的成本不是那几十美元，是暴露。** 以为买到的是一天的信息，实际买到的是一天的未知风险。
3. **规则里有出口，出口就会被用。** 修复不是「下次更坚决」，而是把出口从文案、流程、话术里一起删掉——承诺不修复，机制修复。
4. **防守向与进攻向不对称。** 钟外的防守退出最多扣到 A-；钟外的进攻（持有 / 加仓 / 追涨）才是纪律的主战场（见 [[mindset-structure-pairing]]）。
5. **系统的时序也是纪律的一部分。** 先转移后评估 = 先销毁证据；评估必须排在任何改写状态的步骤之前。
