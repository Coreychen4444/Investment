# 利率到企业估值的完整传导框架

> 状态：按需方法参考（2026-09-05）
> 适用范围：AI 新闻与宏观相位雷达的宏观判断、Tier-1 事件情景树、跨资产验证、公司 read-through 与后续估值模型  
> 所有者：市场情报采集任务
> 原则：宏观只提供方向先验和风险环境，不产生交易授权；价格结构与技术执行仍是最后一公里确认。

本文件供需要深入分解利率与公司估值时查阅。日常运行以 `tasks/intelligence/radar.md` §5.1 与 [[macro-inference-contract]] 为准；后者优先于本文件的顺序、固定时间窗、概率与公司示例。既有有效数据可复用，不要求每轮通读、逐步执行或重建所有公司卡。以下公式、渠道和示例用于解释机制，不直接设定本轮事实、方向或数值。

## 1. 目标

本框架展示利率渠道的一种分析路径，不是所有宏观冲击必须经过的串行链。需求、供给与监管也可直接改变现金流；融资、折现率与风险溢价渠道可同时发生。价格只能检验市场反应，不能独立识别EPS变化：

\[
\boxed{
宏观事实与政策冲击
\rightarrow
市场相对预期的 surprise
\rightarrow
政策反应函数
\rightarrow
2Y/10Y/30Y 与信用曲线
\rightarrow
金融条件
\rightarrow
公司 EPS 与估值倍数
\rightarrow
股价
\rightarrow
技术与跨资产确认
}
\]

在EPS为正且盈利口径一致时，可用以下恒等式表达价值分解：

\[
\boxed{P = EPS \times PE}
\]

EPS与PE均为正且口径可比时，对数变化可分解（恒等式本身不提供因果识别）：

\[
\Delta \ln P
=
\Delta \ln EPS
+
\Delta \ln PE
\]

负EPS、接近零EPS或跨零时不使用对数EPS/PE；改用正常化现金流、企业价值至股权价值的桥和完全稀释股数。必要时单独识别股权风险溢价、信用利差、稀释和资金流，禁止用“利率涨跌”直接跳到“股票涨跌”，也不从股票上涨反推盈利改善。

## 2. 四层认识论

解释利率时区分以下四类变量，按问题选择需要展开的部分。

| 类型 | 典型变量 | 解释 |
|---|---|---|
| 政策制定 | 联邦基金目标区间、准备金利率、QE/QT操作规则 | 由央行或政策机构决定 |
| 市场定价 | 2Y/10Y/30Y国债、TIPS、SOFR、企业债收益率 | 由交易价格形成 |
| 机械计算 | 曲线利差、名义国债减TIPS、企业债减国债 | 从市场价格计算 |
| 模型推断 | 中性利率、期限溢价、纯预期通胀、股权风险溢价 | 无法直接观察，只能估计 |

必须使用准确措辞：

- 联储能直接控制隔夜政策利率附近的资金价格，不能行政决定10Y或30Y。
- 盈亏平衡通胀是通胀补偿，不等于纯通胀预期。
- TIPS实际收益率仍包含实际期限溢价和流动性因素，不等于纯预期实际短率。
- 期限溢价是模型估计，不得写成可直接观察的事实。
- 中性实际利率 \(r^*\) 是模型估计，不是FOMC设定值。

## 3. 宏观政策如何进入利率曲线

### 3.1 货币政策

货币政策主要通过三条路径作用：

1. **政策路径**：当前政策利率和对未来加降息的预期；
2. **资产负债表**：QE/QT改变久期供给、流动性和期限溢价；
3. **前瞻指引**：改变市场对未来短端利率的概率分布。

货币政策松紧不能只看名义政策利率，应比较实际政策利率与中性实际利率：

\[
\text{Policy Gap}
=
(i_{\text{policy}}-E\pi_{\text{near}})
-r^*
\]

- Policy Gap > 0：倾向限制性；
- Policy Gap < 0：倾向宽松；
- 结论必须说明采用的预期通胀口径与 \(r^*\) 估计，不得伪装成精确真值。

### 3.2 财政政策与国债供给

财政扩张可同时影响：

\[
财政扩张
\rightarrow
增长预期\uparrow
+
通胀风险\uparrow
+
国债净供给\uparrow
\]

它可能推高10Y/30Y，即使市场同时预期联储降低短端利率。财政部回购不自动等于QE；必须联合检查净发行、TGA、准备金、回购期限、期限溢价与风险资产反应。

### 3.3 供给冲击与商品

原油、关税、供应链和地缘冲击可产生：

\[
成本冲击
\rightarrow
通胀预期\uparrow
\rightarrow
降息空间\downarrow
\]

但若冲击同时打击需求，则可能形成：

\[
短期通胀\uparrow
+
中期增长\downarrow
\]

此时2Y、10Y、30Y可能方向不同，必须分期限推演。

## 4. 收益率曲线的第一性原理

### 4.1 长端收益率

任意 \(n\) 年期名义国债收益率可近似拆为：

\[
\boxed{
y_n^{N}
\approx
\frac{1}{n}
\sum_{t=1}^{n}E(i_t)
+
TP_n
}
\]

其中：

- \(E(i_t)\)：未来短期名义利率路径；
- \(TP_n\)：期限溢价。

名义利率还可近似拆为：

\[
\boxed{
y_n^{N}
\approx
y_n^{R}
+
IC_n
}
\]

其中 \(IC_n\) 是通胀补偿：

\[
IC_n
=
E(\pi_n)
+
IRP_n
+
LP_n
\]

- \(E(\pi_n)\)：预期通胀；
- \(IRP_n\)：通胀风险溢价；
- \(LP_n\)：名义债与TIPS流动性差异等残差。

### 4.2 三个关键期限

| 期限 | 核心定价内容 | 常见误读 |
|---|---|---|
| 2Y | 未来1–2年政策路径、近端通胀与增长对联储反应函数的影响 | 把2Y当成联储直接设定 |
| 10Y | 未来短率平均值、长期实际增长/通胀、中性利率预期与期限溢价 | 把10Y全部解释成加息次数 |
| 30Y | 超长期通胀不确定性、财政供给、期限溢价、养老金与保险久期需求 | 把30Y上涨自动写成经济强劲 |

关键规则：

\[
\boxed{
2Y看近端政策路径；
10Y看中长期贴现率；
30Y看长期政策/通胀预期、财政供给和久期补偿。
}
\]

但它们只是定价节点，不与EPS或PE机械一一对应。

### 4.3 曲线组合的基本解释

| 曲线变化 | 初始解释 | 必查反证 |
|---|---|---|
| 2Y↑、10Y↑、30Y↑ | 全曲线鹰派或通胀/实际利率重定价 | 是否主要来自期限溢价 |
| 2Y↓、10Y↓、30Y↓ | 宽松、通胀下降或增长恐慌 | 信用是否恶化、EPS是否下修 |
| 2Y↓、10Y/30Y↑ | 扭转式陡峭化：短端下行、长端上行；近端宽松与长期财政/通胀风险可能并存 | 10Y实际利率、通胀补偿、拍卖与供给 |
| 2Y↑、10Y/30Y较稳 | 近端政策更鹰、长期锚定尚未改变 | 是否只是事件前短端噪音 |
| 2Y稳、10Y/30Y↑ | 期限溢价、财政供给或长期增长/通胀重估 | 美元、黄金、实际利率和拍卖表现 |

## 5. 市场交易的是预期差，不是政策动作本身

所有事件先计算：

\[
\boxed{
Surprise
=
新信息隐含路径
-
事件前已计价路径
}
\]

必须回答：

1. 事件前市场已经计价多少加息或降息；
2. 新数据改变了增长、通胀还是政策反应函数；
3. 变化首先落在2Y、实际利率、通胀补偿还是期限溢价；
4. 价格反应是否与事件时间对齐；
5. 是否存在提前计价、分项结构、修订或其他冲击覆盖。

“如期降息”可能没有新增利好；“降息”也可能因衰退和信用压力而利空股票。

## 6. 从国债到企业资本成本

### 6.1 债务成本

企业新增债务成本近似为：

\[
\boxed{
k_d(m)
=
y_{\text{Treasury},m}
+
CS_m
+
F_m
}
\]

其中：

- \(m\)：匹配的融资期限；
- \(CS_m\)：信用利差；
- \(F_m\)：发行、担保、流动性和结构条款成本。

短期浮息债通常更接近：

\[
k_d
\approx
SOFR + Spread
\]

### 6.2 股权成本

名义现金流必须使用名义贴现率：

\[
\boxed{
k_e
=
r_f
+
ERP
+
\text{company-specific risk}
}
\]

不得把实际无风险利率与名义EPS增长直接混用。

### 6.3 WACC

\[
\boxed{
WACC
=
\frac{E}{D+E}k_e
+
\frac{D}{D+E}k_d(1-T)
}
\]

国债收益率下降但信用利差和ERP上升时，WACC仍可能上升。这是衰退式降息不一定利好股票的核心。

## 7. 公司暴露卡：先识别商业模式与资产负债表

把利率推演到公司时，核对与结论有关的暴露。以下维度可作为参考；已有资料仍有效时复用并标明日期，有实质变化才更新，无需每轮新建完整卡片。

### 7.1 估值久期

- 当前利润与自由现金流规模；
- 价值有多少来自5年、10年以后；
- 估值倍数与永续增长假设；
- 股票是否属于高久期、高预期资产。

近似关系：

\[
\frac{\Delta P}{P}
\approx
-D_{\text{equity}}\Delta k
\]

久期越长，实际利率和ERP变化对PE越敏感。

### 7.2 净利息头寸

高自由现金流不等于高净现金。必须分别读取：

- 可重新定价的现金、短期国债和有价证券；
- 浮动利率债务；
- 未来1、2、3、5年的到期债务；
- 固定利率长期债务；
- 租赁、项目融资、担保和表外义务。

净利息变化近似为：

\[
\Delta NI_{\text{interest}}
\approx
C_{\text{repricing}}\Delta r_{\text{asset}}
-
D_{\text{floating}}\Delta r_{\text{short}}
-
D_{\text{refi}}\Delta(y_m+CS_m)
\]

对应直接EPS影响：

\[
\boxed{
\Delta EPS_{\text{direct}}
\approx
\frac{
\Delta NI_{\text{interest}}(1-T)
}{
\text{Diluted Shares}
}
}
\]

### 7.3 债务重新定价规则

- 已发行固定票息债：市场利率变化不改变其现金票息；
- 固定票息债只有到期再融资、回购或条款触发时才重新定价；
- 浮息债：通过SOFR等短端基准直接影响利息费用；
- 可转债：固定票息部分不随市场利率变化；需另计本金增值、发行费摊销、转股稀释和到期再融资；
- 新债：由发行时对应国债期限、信用利差和结构条款共同决定；
- 会计公允价值变化不得与现金利息变化混为一谈。

### 7.4 资本密集度与融资模式

必须识别：

- CAPEX / Revenue、CAPEX / Operating Cash Flow；
- 内部现金流能否覆盖CAPEX；
- 是否依赖持续发债、可转债、ATM或项目融资；
- 项目回收期与债务期限是否匹配；
- 客户预付款、长期合同和担保是否降低融资风险。

### 7.5 经营周期与第二阶传导

利率还可通过以下渠道间接影响EPS：

- 消费信贷、房贷、汽车贷款和企业投资；
- 广告预算、云和AI CAPEX；
- 美元汇率及海外收入换算；
- 客户融资能力和订单推迟；
- 原材料、工资和能源成本；
- 回购规模与流通股数；
- 信用紧缩和供应商融资。

### 7.6 股息与类债券属性

成熟防御股即使增长低，PE仍会受利率影响：

\[
PE_{\text{forward}}
\approx
\frac{\text{Payout Ratio}}{k_e-g}
\]

长端国债收益率上升会提高无风险替代收益，使高分红稳定现金流公司的股息率和盈利收益率需要重新定价。防御股在加息期可能相对抗跌，不等于绝对受益。

## 8. 区分 EPS、PE 与 ERP 的影响

按相关性区分以下渠道，可用自然段、列表或表格表达；没有实质影响的渠道无需机械填栏。

| 栏目 | 回答的问题 |
|---|---|
| 直接EPS | 现金利息、浮息债、到期再融资、税后利息是否改变 |
| 间接EPS | 需求、客户融资、CAPEX、汇率、成本、回购如何变化 |
| PE | 实际利率、估值久期、长期增长率与股息替代关系如何变化 |
| ERP/信用 | 风险溢价和信用利差是否放大或抵消无风险利率变化 |

禁止把同一影响重复计算。例如“10Y上升提高WACC”已经进入估值时，不得在没有实际新增利息或需求变化的情况下再次下调EPS。

股价情景：

\[
P_1
=
EPS_1
\times
PE_1
\]

\[
EPS_1
=
EPS_0
+
\Delta EPS_{\text{direct}}
+
\Delta EPS_{\text{indirect}}
\]

\[
PE_1
=
f(r_f, ERP, g, payout, D_{\text{equity}})
\]

## 9. 公司类型映射

| 类型与例子 | 2Y主要影响 | 10Y主要影响 | 30Y主要影响 | 首要变量 |
|---|---|---|---|---|
| 高估值低融资依赖软件：STOCK_V | 风险偏好，PE中 | 估值久期，PE高 | PE中低 | 实际利率、ERP |
| 高盈利净现金AI/平台：STOCK_A、STOCK_GO、STOCK_E | 现金收益与经济周期；直接EPS低至中 | PE中高；客户CAPEX二阶影响EPS | PE中 | 实际利率、广告/云需求、客户CAPEX |
| 高CAPEX AI基础设施：STOCK_O、STOCK_G | 浮息债、新融资与流动性，EPS/PE | 中期融资、WACC与PE，EPS/PE | 超长期项目与融资预期，通常次于2Y/10Y | 债务结构、信用利差、客户合同、CAPEX覆盖 |
| 稳定消费：KO、MCD | 经营周期和短债；未必受益 | 股息替代和PE；再融资逐步影响EPS | 类债券估值和长期再融资 | 定价权、净负债、股息率 |
| 银行：JPM | 净息差、存款beta，EPS高 | 曲线斜率、证券与贷款收益，EPS | 通常次要 | NII、存款成本、信用损失 |
| REIT/公用事业：PLD、NEE | 短债与流动性 | 资本化率、项目WACC，PE/EPS | 超长项目现值与融资，PE/EPS高 | 固定债到期表、项目久期、监管回报 |

这些只是先验。最终敏感度必须由最新资产负债表、债务期限、商业合同和估值结构覆盖，禁止永久写死。

## 10. 六类标准宏观路径

### 10.1 通胀偏热、政策更鹰

\[
通胀surprise\uparrow
\rightarrow
政策路径上修
\rightarrow
2Y\uparrow
\]

若10Y实际利率同步上升：

- 高久期成长股：PE下行；
- 浮息和再融资企业：未来EPS下行；
- 净现金企业：利息收入可能上行，但需与PE压缩比较；
- 防御消费：可能相对抗跌，绝对PE仍受压；
- 银行：早期NII可能改善，后期需防存款成本和坏账。

### 10.2 通胀回落、增长稳定

\[
通胀\downarrow
+
增长稳定
\rightarrow
2Y/10Y实际利率\downarrow
\]

若信用利差稳定：

\[
PE\uparrow
+
EPS稳定
\]

这是高久期AI和资本密集AI最友好的软着陆路径。

### 10.3 增长恐慌、衰退式降息

\[
增长预期\downarrow
\rightarrow
2Y/10Y\downarrow
\]

但：

\[
信用利差\uparrow
+
ERP\uparrow
+
EPS预期\downarrow
\]

国债利率下降可能被风险溢价和盈利下修完全抵消。必须检查HY/IG OAS、VIX/MOVE、宽度与AI beta。

### 10.4 财政与期限溢价冲击

\[
2Y稳定或下降
,\quad
10Y/30Y\uparrow
\]

若由国债供给、财政赤字或期限溢价主导：

- 软件和半导体：主要压PE；
- STOCK_O/STOCK_G：压PE并提高未来融资门槛；
- PLD/NEE：PE与长期项目WACC双重承压；
- KO/MCD：股息替代吸引力下降；
- EPS通常不会当日机械下降。

### 10.5 强增长推高实际利率

\[
增长预期\uparrow
\rightarrow
实际利率\uparrow
\]

此时存在对冲：

- PE因贴现率上升而下降；
- 周期与需求敏感企业EPS上升；
- 防御股可能相对落后；
- 最终股价取决于EPS上修能否覆盖PE收缩。

### 10.6 信用或流动性冲击

\[
信用利差\uparrow
+
融资可得性\downarrow
+
波动率\uparrow
\]

此时风险溢价往往比无风险利率更重要：

- 资本密集与持续融资企业首当其冲；
- 净现金企业相对占优；
- 仅看到国债上涨或收益率下降，不得写成长久期股票利好。

## 11. 一阶、二阶、三阶传导

阶数由因果距离定义，不等于固定持有期，也不决定哪个资产先动。以下按渠道组织；实际观察窗口由事件时间、交易时段和机制决定。盈利预期可以立即重估，融资/经营实现可能跨季，未知渠道不强填。

### 直接定价与预期差

回答：

- 数据相对共识如何；
- 政策路径如何变化；
- 2Y、10Y、30Y分别如何反应；
- 名义变化来自实际利率、通胀补偿还是期限溢价；
- 美元是否同步。

### 市场扩散、延续与竞争解释

回答：

- 信用、MOVE、VIX是否确认；
- 曲线形态是否延续；
- QQQ、SMH、IWM与防御/周期风格如何分化；
- 黄金、BTC、原油是否支持同一机制；
- 市场是否从最初反应切换到第二叙事。

### 融资与经营实现

回答：

- 金融条件是否影响企业融资、CAPEX和客户需求；
- 分析师是否调整收入、利润率、利息费用和EPS；
- 估值倍数是否形成稳定重定价；
- 公司是否改变发债、回购、投资或资本配置；
- 技术结构是否确认宏观先验。

## 12. 深入分析的参考步骤

需要深入分析时，可从以下问题中选择与事件有关的部分。步骤顺序、展开深度和输出形式由证据与任务决定。

### Step 1：钉住事实与surprise

写明事件、实际值、共识、前值修订、发布时间和事件前政策定价。

### Step 2：识别政策反应函数

判断变化主要来自增长、通胀、就业、财政、流动性、供给冲击或组合。

### Step 3：分解曲线

分别解释：

- 2Y：政策路径；
- 10Y：预期短率均值、实际利率、通胀补偿、期限溢价；
- 30Y：超长期通胀、财政供给和期限补偿；
- 2s10s、10s30s：曲线相对变化。

分解证据不足时写“未确认”，不得强行选唯一原因。

### Step 4：检查信用和风险溢价

检查HY/IG OAS、交易代理、MOVE、VIX、美元与流动性。JNK/HYG不得等同OAS。

### Step 5：生成相关公司暴露卡

只对active、watchlist或高相关AI环节生成，读取最新财务与融资事实，标明as-of。

### Step 6：拆分EPS与PE

输出直接EPS、间接EPS、PE、ERP/信用四栏，并标明时效。

### Step 7：形成股价路径

至少给出：

- 基准路径；
- 竞争路径；
- 最大反证；
- 价格与跨资产确认条件；
- 证伪条件。

### Step 8：交给技术层确认

宏观输出只能形成方向先验。QQQ/SMH、板块相对强弱、个股结构、量价与zone/gate仍负责最终确认和执行。

## 14. 后续估值模型的数据接口

为了逐步形成自有估值模型，公司层应积累以下字段：

| 维度 | 建议字段 |
|---|---|
| 基准盈利 | Revenue、EBIT margin、tax rate、diluted shares、EPS、FCF |
| 现金 | cash、short-term investments、average yield、repricing speed |
| 债务 | floating debt、fixed debt、coupon、maturity buckets、credit spread |
| 融资 | planned capex、external funding need、convertible/ATM capacity |
| 久期 | equity duration estimate、cash-flow timing、terminal value share |
| 经营 | cyclicality、pricing power、FX exposure、customer financing dependence |
| 估值 | base PE、payout、growth、ERP、matched risk-free curve |
| 风险 | dilution、refinancing wall、lease/project obligations、concentration |

情景估值：

\[
EPS_s
=
EPS_0
+
\Delta EPS_{\text{direct},s}
+
\Delta EPS_{\text{indirect},s}
\]

\[
PE_s
=
f(r_{f,s}, ERP_s, g_s, payout_s, D_{\text{equity}})
\]

\[
P_s
=
EPS_s\times PE_s
\]

贝叶斯加权：

\[
E[P]
=
\sum_s p_s P_s
\]

模型必须保留：

- 情景概率有依据才给区间并说明来源；依据不足保留null，不以宽区间伪装校准；
- 输入数据as-of；
- 主导假设和反证；
- EPS与PE是否存在重复计量；
- 技术价格确认与模型价值之间的差异。

## 15. 禁止的分析捷径

- “降息 = 股票利好”；
- “加息 = 所有公司利空”；
- “2Y下降 = 10Y和30Y必然下降”；
- “国债回购 = QE”；
- “高自由现金流 = 净现金 = 加息提高EPS”；
- “非成长股PE不受利率影响”；
- “固定利率债务会随加息立即增加票息”；
- “可转债票息低，所以没有本金增值、稀释或再融资风险”；
- “JNK下跌 = OAS扩大”；
- “国债收益率下降足以抵消信用利差与ERP上升”；
- “同一个WACC冲击同时下调PE和EPS”；
- “宏观方向先验可以绕过技术gate、zone或风控cap”。

## 16. 相关性复核参考

深入分析时可检查以下相关问题。日常短报不要求逐项展开；事实、来源、无重复计量与权限边界仍遵守运行规格。

1. 写明市场预期差，而不只写事件本身；
2. 分别解释2Y、10Y、30Y；
3. 区分名义、实际、通胀补偿和期限溢价；
4. 检查信用利差、ERP和波动率是否抵消无风险利率变化；
5. 读取相关公司的最新资产负债表与融资条款；
6. 区分高现金流、高现金和净现金；
7. 区分固定债、浮息债、到期再融资与未来新增融资；
8. 分栏输出直接EPS、间接EPS、PE和ERP/信用；
9. 对有证据的直接与后续渠道给出观察窗和确认/证伪，未知渠道可空；
10. 价格结构只确认市场响应，不能据此确认EPS；交易授权由技术层自身规则处理；
11. 不产生订单、仓位、gate、zone或cap写入。
