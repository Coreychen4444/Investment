# 宏观观测选择与跨资产证据

2026-09-05补充并复审。配合 [[macro-inference-contract]] §3A 使用。目标是综合官方总量、企业经营、政策与金融市场，判断同一个经济机制；关注名单决定交易研究目标，不能限制宏观证据来源。下列公司是观测对象示例，不是投资推荐，也不是每天全部检索的清单。此版本是待验证的候选设计，不声称指标集合已达到最优或统计上的最小充分。

## 0. 先定义信息要改善哪个判断

观测价值取决于它能否改变事件重新定价、1–10日传导持续性、1–3月现金流/融资判断，或识别被均值掩盖的尾部风险。它们分别评估，不优化一个含混的“宏观预测准确率”。宏观结果继续只有研究和方向先验效力，不产生交易写权限。

每项拟加入核心的观测先回答：**在已有信息之外，如果这项数据不同，会改变哪个判断、区分哪两个解释、影响什么曝险、何时能验证？** 暂时不能回答的内容列为背景或候选，不能因为来源知名或跨了一个资产类别就提高权重。尚未识别的冲击保留开放调查，不为填满维度强行归类。

选择顺序是决策关联、条件信息增量、可获得时点与可靠性，最后才是采集成本。相关性高不自动意味着可删除：一个来源可能更早，另一个更可靠或覆盖不同尾部。反之，同一来源的同比、月比、移动平均可以帮助读趋势，但不是三份独立证据。正常时期没有报警，不足以淘汰尾部风险观测。

## 1. 两类覆盖范围

- `active/watchlist`：回答当前研究哪些投资目标，继续由现有universe工具决定。
- 宏观观测对象：回答经济和融资环境怎样变化。USDJPY、WMT等即使不在交易名单，也可作为来源；不因此加入watchlist或获得交易权限。用户明确要求不出现在任何任务输出的标的仍排除。

代表性企业的客流、消费结构、货量、贷款或资本开支等数据，可以在处理公司特有因素后支持宏观状态。企业自身EPS、股价、估值变动不能直接等同宏观方向。同一条经营信息若已用于宏观增长判断，在组合影响中只展示传导，不再次计成独立的宏观利好。

## 2. 观测地图

| 要判断的问题 | 官方/总量基准 | 企业或市场交叉观察 | 必须排除的混淆 |
|---|---|---|---|
| 美国消费是否扩张、是否分化 | 实际PCE、实际可支配收入、储蓄、就业/工时、零售分项 | WMT/COST/TGT的客流与客单；HD/LOW的大额家居需求；支付网络披露；旅行/餐饮经营 | 价格上涨、市场份额、收入群体、商品/服务差别、海外业务、公司执行；支付网络交易额不等于全部消费 |
| 家庭与企业是否更难融资 | 贷款标准、消费信贷/拖欠、银行数据 | 银行财报的拖欠/核销/贷款增长；发债条款；OAS和匹配久期的信用表现 | 单家银行客户结构、证券损益、并购；利差窄不保证边际借款人借得到钱 |
| 工业与货物周期怎样变化 | 工业生产、耐用品订单、制造业调查、贸易数据 | 物流公司货量/收益率、设备订单/积压、铜和运输价格 | 价格与货量、罢工/天气/航线变化、去库存、区域与公司份额；铜上涨未必是需求强 |
| 政策与跨境融资是否收紧 | Fed/BOJ等央行政策与整条路径、匹配期限美日利差 | USDJPY、日元交叉盘、FX波动/偏斜、可得头寸与资金流、跨币种融资成本 | 美元共同因素、日本特有变化、干预、避险、套息减仓；汇率方向不能单独识别资金流 |
| 通胀来自需求还是供给 | CPI/PCE分项、工资/生产率、进口价格 | 零售商成本/提价/促销、油气/航运、交货期 | 单一品类监管、基数、补贴、税率；成本下降不自动代表总需求转弱 |
| AI投资是否可持续兑现 | 资本开支与生产等背景数据 | 云厂商收入/资本开支/变现，芯片/存储订单，电力/建设交付，融资条款 | 同一客户预算在上下游重复出现；融资/订单/预付款与终端付费、收入和FCF不可互换 |

企业来源优先IR财报、演示、电话会和申报。管理层对“消费者健康”的描述属于公司观察，不能不经数据核对就当作全国统计。样本应覆盖不同渠道、收入群体和品类，不能只选支持当前观点的公司。

### 2A. 常设核心、发布更新与条件扩展

“常设”指每轮知道它的最新状态、缺口及下一更新时间，不要求低频数据每日重抓。核心由五份持续维护的底稿组成，而非固定数量的ticker：

| 常设对象 | 最低需要知道什么 | 更新方式 |
|---|---|---|
| 事件与事前基准 | 下一重要事件；发布前共识及可得分布、旧指引、政策合约路径、同品种事件前报价；上轮假设及到期 | 日历/指引有变化时更新，事件前冻结；来源不可得就保留缺口 |
| 经济状态 | 实际需求与收入、劳动投入及修订、通胀分项与扩散；贷款需求和供给的不同状态 | 官方发布更新，保留当时版本；代表性企业解释结构和分歧 |
| 金融传导 | 名义/实际利率与曲线、信用、美元/日元、短期融资、波动和股票响应；注明各自时钟 | 每轮检查已有结构化快照；尚未接入的维度显式未知 |
| AI兑现与资金来源 | 最终付费、买方预算、合同期限、可交付产能、收入与回款、capex及融资缺口 | 财报、合同、融资、交付和监管更新；稳定底稿复用 |
| 暴露与脆弱性 | 共同客户/融资来源、币种与期限错配、交付/到期日；真实持仓权重和可核期权风险 | 持仓或关键事实改变时更新；缺数据不得假装已完成组合优化 |

扩展调查在具体触发后展开：

- 日元汇率/波动、利差或BOJ政策有实质变化：查政策路径、交叉盘、融资与对冲、可得头寸；现货单独不足以确认套息平仓。
- 消费新数据、零售商财报发布，或“总量稳健/边际家庭转弱”出现分歧：查WMT等不同渠道、群体的经营与信用证据。
- 云资本开支、客户大合同、融资或交付节点改变：追到同一最终客户和兑现阶段，不仅收集供应链的新闻数量。
- 信用分层、回购偏离、市场深度或波动结构异常：展开融资数量、抵押品、期限、强制减仓的竞争解释。
- 能源/航运、关税/出口许可、财政发行结算、中国需求、台湾/韩国供给等出现事件或关联曝险变化：展开对应渠道。

实质变化的阈值若要自动化，须按品种、波动背景与发布时间预先定义并验证；不能临时设一个百分比来吻合当天故事。每轮还做一次简短盲点检查：上述政策/供给/融资类别是否出现新冲击，是否有反对主判断的来源或无法解释的市场异动。不能因当前假设没覆盖某机制就永远不检索它；稳定类别无需写成长篇新闻。

## 3. USDJPY：跨境融资和风险传导的常设观察

USDJPY表示每美元对应多少日元：数值下降是日元升值。每轮读取可用结构化快照，并检查1日/数日变化、波动幅度和最近政策催化；没有实质变化时简写。它已经在现有快照的采集范围内，但美日完整政策路径、FX期权和头寸数据尚未全部接入，不能声称具备完整套息风险监控。

应至少区分四种候选解释：

| 观察组合 | 待检验解释 | 对AI美股的条件影响 |
|---|---|---|
| USDJPY温和下降，美国利率下降，信用/风险波动平稳 | 美国政策路径缓和或美元普遍回落 | 折现条件可能缓和；不能仅凭日元升值判风险收缩 |
| 日元快速广泛升值，日本前端利率/政策预期上修，FX与风险资产波动上升 | 日元融资压力或套息去杠杆候选 | 杠杆及保证金反馈可能冲击高beta资产，即使当期EPS未变 |
| USDJPY下降，美国增长数据恶化，美债上涨、信用走弱 | 美国增长担忧兼避险 | 低利率与盈利/融资压力可能并存，净影响需分解 |
| 日元突发升值但利差变化小，出现官方干预线索 | 干预或短期头寸调整候选 | 关注持续性和实际市场压力；不能直接称全球资金撤出 |

这些是条件组合，不是确定性分类器。USDJPY与DXY包含重叠信息；日元交叉盘也共享日元成分，不能逐个独立计票。JPY升值是否增加融资负担取决于借款币种、资产币种、杠杆和对冲；现货变化不足以测量套息规模、日资回流或“日本卖美债”。CFTC等公开头寸只是部分市场，不能代表全部杠杆。

BIS对2024年8月的研究记录了货币与股权杠杆交易平仓及保证金反馈放大市场波动，同时强调套息头寸规模难以完整观测。因此将USDJPY作为风险传感器有依据，但不能把每次升值自动归因于套息平仓。[BIS Bulletin 90](https://www.bis.org/publications/bulletin-90-market-turbulence-and-carry-trade-unwind-august-2024)

## 4. WMT：消费的企业观测点

在财报、经营更新或相关消费数据发布时更新WMT底稿；其他轮次沿用仍有效的最新季度事实并标记期间，不把旧财报重报成当天新闻。至少拆解：

1. 美国业务与国际业务；同店与新店/并购/汇率贡献。
2. 交易笔数、客单与可获得的数量/价格信息；客单不等于销量，粗略扣通胀不能冒充严格实际量。
3. 必需/可选、食品/一般商品、线上/线下；药品监管等特殊因素。
4. 不同收入群体、市场份额、促销与客户迁移；“WMT份额上升”既可能伴随消费增长，也可能伴随预算转向低价渠道，不能独自证明消费降级。
5. 指引相对原指引与可核共识的变化、毛利率/库存、管理层措辞和可验证经营数据。

先与覆盖期匹配的PCE/零售、其他渠道及收入/信用状况对照，再判断它是全国需求、群体分化、份额迁移还是公司特有变化。WMT盈利可能受广告、会员、效率、药品或国际业务驱动，EPS超预期不能直接翻译成美国消费强。

## 5. 如何形成综合判断

每个主题按“共同假设—不同测量视角—竞争解释—下一判别点”组织：

- **总量层**估计增长、通胀和融资背景。
- **企业层**解释分项、群体、价格与数量、预算与订单的变化。
- **定价层**观察市场相对事前预期作了什么调整。
- **风险层**检查信用、融资可得性、杠杆与波动反馈。

四层可以方向不同：消费仍有韧性，但资金面因日本政策/杠杆平仓承压，是允许存在的组合；不能平均成0，也不能用一家企业的好财报否定快速资金风险。

先对齐观察对象、地区、单位、季调、同比/环比、发布时点和覆盖期，再解释差异。WMT季度同比与PCE月度环比不能直接相减，也不能只因正负不同就叫证据冲突。WMT销售、零售和PCE的覆盖存在重叠，同属消费证据组，不能当三个独立似然相乘。

综合的依据是代表性、时效、是否超出预期、是否区分竞争解释及与组合的实际关联。未校准前不设“USDJPY占20%、WMT占10%”的固定权重，不按利好/利空条数投票。

## 6. 新闻窗口与有效知识窗口

新闻新增窗口仍按上轮成功运行至今；宏观背景使用当时可获得的**最新有效知识**，可以跨越这个窗口：

- 汇率/利率/信用/波动：每轮检查新报价；区分即时与背景，用事件同窗数据作确认。
- 初请、资金量等周频数据：随发布更新；不把周频变化当盘中事件响应。
- 消费/就业/通胀月报：保留近期趋势与修订，新发布覆盖旧版本；无新数据不每日复制全文。
- WMT等财报：保留最新有效季度、指引与发布日期；下一财报或重要更新到来时重新判断。

低频数据“仍是最新”不意味着足以解释刚发生的冲击。每轮输出当前判断、此次哪些输入改变了它、哪些背景未变、冲突或未知在哪里、下次观察期限。此地图是研究合同；本轮未创建新的采集器、加权模型或自动调度。

## 7. 相比现有框架，优先补齐什么

下表是建设顺序，不是资产收益权重。大部分机制在方法合同里已经存在；不足主要是可复核的数据载体、口径与验证。宏观六组不再机械扩成几十个独立因子。

| 优先事项 | 最低可用观测与比较 | 当前边界 |
|---|---|---|
| 先补事前预期与价格门槛 | 调查共识及来源截止时间、可得分歧/修订；旧公司指引；分会议政策路径；固定事件前报价 | 文档和事件计划有要求，快照没有完整预期账本。调查中值、衍生品隐含分布、股票隐含增长假设是不同对象；风险溢价和估值模型假设须保留。单靠PE或“利好不涨”不能识别已计价程度 |
| 先补机制覆盖与真实曝险 | 哪个机制是已观测、未知或混杂；各期限最关键的缺口；实际权重、期权期限/敏感度及共同客户/资金来源 | 快照字段齐全率只诊断采集，不能证明研究完整。ticker覆盖不等于组合暴露，缺实时敏感度时只作定性判断 |
| 补融资价格、数量与可得性 | 同窗OAS及匹配无风险利率；SOFR/EFFR相对管理利率、分布；贷款标准与需求、实际融资完成和条款、抵押/到期/资本开支资金缺口 | 现有快照主要覆盖利率、OAS/ETF与资产负债表存量，资金市场价差和借款人供给尚不完整。贷款下降可能是需求弱；低平均利差可能遗漏边际融资受限者 |
| 补AI兑现阶段与会计可比性 | 付费与留存/消费量；合同可取消性、未来12月兑现和客户集中度；供电/验收；回款、租赁、现金capex及融资 | 原合同已提到单位经济和融资，尚无完整跨公司兑现账本。按§8核对披露，未披露的利用率、客户ROI或真实推理利润率不能估成事实 |
| 补经济内部结构与边际变化 | 实际收入/消费、工时/初请/修订；价格与数量、必需/可选、不同收入和借款群体；工资与生产率、服务/住房/商品通胀 | 月报/季度事实适合背景与趋势，周频更早但噪声更大；高频不自动更优，企业样本不能替代全体。WMT属于此处的发布型观测 |
| 补损失放大条件 | 期限/币种错配、现金缺口与再融资窗口；波动期限结构/偏斜、实际广度、流动性和可得头寸 | 现有VIX/MOVE/USDJPY只覆盖部分。期权OI不识别交易商净方向，公开持仓覆盖不全，成交量不等于深度；不得声称已知全市场杠杆或确定GEX |
| 按需增加交叉诊断 | ANFCI及其风险/信用/杠杆分项、超额债券溢价等模型估计；能源/运输/工业与海外分项 | 用来挑战现有解释，不能与已有组成项重复计票；注意周/月频、模型修订和历史版本，不能当盘中确认 |

融资供给有现实官方来源：联储SLOOS分别调查贷款标准/条款和贷款需求；纽约联储SCE Credit Access区分申请、拒绝和需求受抑制等借款经历，可补充只看信贷余额的盲点。二者是慢背景，不能测量此刻的融资压力。[SLOOS](https://www.federalreserve.gov/data/sloos.htm)；[SCE Credit Access](https://www.newyorkfed.org/microeconomics/sce/credit-access.html)

芝加哥联储NFCI汇总105项金融变量，ANFCI调整经济活动和通胀影响，并提供风险、信用、杠杆等分项。使用它是综合诊断，不凭增加一个综合指数就增加一份独立证明。[NFCI方法](https://www.chicagofed.org/research/data/nfci/about)

## 8. AI专题：把投入、兑现与可融资性连起来

以下是分析阶段，不要求商业活动严格按这个时间顺序发生；预付款、预建产能和租赁会改变现金时序。必须逐段定位，不能默认每个箭头已经成立。

| 阶段 | 优先核对 | 不能跳过的问题 |
|---|---|---|
| 最终价值与经济性 | 可比口径的付费席位/消费收入、留存、量价、客户披露的实际用途；扣除促销/免费额度的可得信息；广告变现或内部降本的可核效果 | token、注册用户或试用增长是否变成付费或实际经济收益？单位价格下降是效率扩量还是竞争压价？AI价值不必单独收费；客户ROI和利用率未披露则未知 |
| 预算与合同 | 买方自有经营现金或外部融资；订单/RPO的客户集中、可取消性、兑现期限和旧指引覆盖 | 多年承诺是否被读成当年需求？投资、贷款、云额度和采购义务是否关联？融资依赖不自动意味着虚假需求 |
| 产能与交付 | 已规划、已签约、已供电、已安装、验收可用分别记录；芯片/网络/电力/许可瓶颈 | 规划MW不等于可用算力；供应受限可能推迟收入，也可能掩盖需求变化；数量口径不同不直接相加 |
| 收入与回款 | 收入确认、应收和付款期、客户预付款/递延收入、经营现金与营运资本变化 | 客户付款前置能暂时抬高现金流；收入增长不等于当期回款，供应商与买方不能重复计算同一预算 |
| 资本消耗与融资 | 现金PPE、非现金融资租赁新增、经营租赁义务/付款、折旧政策；受限现金、到期债务、利息和潜在稀释 | 各公司capex/FCF定义不同；不能直接加总租赁新增与未来付款，或重复扣已经进入经营现金的费用。维护/扩张capex未拆分则不编估计 |
| 利润分配与替代 | 买方/供应商议价、GPU/ASIC及训练/推理结构、设备代际、产品组合和可核量价/毛利变化 | 行业capex增长不保证每家公司的利润增长；效率与替代既可能扩大总量，也可能转移利润。不能从总投资额或股价反推供应商份额 |

同一最终客户预算在云厂商capex、供应商backlog、芯片销售中可以提供不同兑现阶段的证据，但只算一个经济资金来源。跨公司加总前匹配会计期间、币种、合并范围及客户/合同关系；并非所有云收入或capex都属于AI。

一个近期口径案例：某超大规模云厂商在2026年中的财年Q4电话会说明，下一财年起调整数据中心和办公楼预计使用年限，使更多未来租赁由融资租赁转为经营租赁；公司capex包括前者、不包括后者，并表示剔除该影响后2026年投资预期不变。因此仅看披露capex变化可能误读实际投资。此例说明需要口径桥，不证明行业资本开支方向。（来源：该公司官方电话会，CFO 在 outlook 前的说明）

季度桥用于判断预算、现金和融资趋势；事件窗口只更新本次新增指引、合同或融资对原假设的影响，不把一条公告直接年化成长期增长。

## 9. 何时纳入、降频或淘汰

新增核心输入先保留简短登记：`hypothesis / horizon / channel / role / evidence_family / source / release_lag / refresh_trigger / competing_explanation / affected_exposure / due_at / limitation`。复用现有来源归档，不强制把不适用字段填满；没有可复核时间、口径和持续可得来源的输入先留研究候选。

每轮主判断只需写一条可检查的更新记录：“上轮判断 → 本次新增事实 → 改变/未改变哪个分支 → 竞争解释 → 下一观测和截止”。坏数据后股价不跌，只说明该窗口反应，不自动证明坏消息已出尽；有相反解释时先识别事件混杂、预期门槛或头寸证据。

选择效果按三个期限分别做滚动样本外评估，使用当时可得数据和原始预测版本。比较只看经济数据、只看价格、完整框架，再逐项/逐机制移除输入；记录预测质量、误报、重大漏报、弃权及有效覆盖、预警提前量、翻转和研究成本。有明确概率才测Brier/log score；机制识别没有可知真值时保留未识别，不靠事后故事给自己判对。

同一事件和重叠收益窗口分组，避免跨训练/验证泄漏或重复计算战绩；阈值在训练期选择并冻结。历史回放之外积累前瞻记录，阶段、品种和来源发生结构变化时重新审查。新闻研究价值与实际交易结果分开，不能未经交易规则约束和成本检验就声称提升收益。

持续没有条件信息增量的重复代理可降频；关键尾部哨兵不能仅按平静时期平均准确率淘汰。暂时拿不到数据的核心机制明确未知，不能找一条不等价的方便指标补满。数据数量、机制覆盖、时效和判断置信度分别展示。

本次落实的是研究选择合同与prompt要求；预期/兑现账本、额外采集器、持仓风险映射和消融评估尚未因此自动实现。没有前瞻验证，不能称“最优观测系统”。
