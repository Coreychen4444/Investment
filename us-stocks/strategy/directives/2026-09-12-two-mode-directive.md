# 2026-09-12 两种交易模式 directive（草案·待裁；判读层已落地，授权层列决策点）

> ⚓ 宁可错过，不可失序；失去节奏，终会成为市场的猎物。

> 语境：用户 2026-09-12 逐字：
> **「目前我们的系统应该仅聚焦某种形态结构 做两种固定的模式
> 1. 做抄底 即止跌底部确认后做反弹或反转行情 后续根据实际走势情况判断反弹还是反转 反弹就尽早清仓 反转就继续拿着 例如这段时间的 STOCK_M 200 / STOCK_IN 85 / STOCK_GO 327 / STOCK_O 195
> 2. 做趋势确认 即现在已经有的模式 等站稳 gate 后的进场 例如 STOCK_E 553 / STOCK_M 223

> 然后把盘后的那个 chart read 重写 不再关注多种形态 仅关注这两种形态已形成或即将形成的标的 未形成的不需要关注」**

## §1 两种模式的机械定义（代码真源 `quant/core/setups.py`）

| 模式 | 定义 | 阶段（判读层） | 关键线 |
|---|---|---|---|
| **🔁 抄底** `bottom_setup` | **底 = 20 日顶（近 20 根最高 high）之后的最低 low（L）**（用户 2026-09-13「STOCK_M 最近的底肯定是在 200」：第一版 20 日最低 low 会把 STOCK_O 9/02 锚在 8/07、STOCK_H 锚在 8/26；第二版最近分形高之后的低把 STOCK_M 9/10 回踩 226 当成底；顶锚两个都对）；人群门 L 距 60 日高 ≥10% **且顶到 L ≥2×ATR20@L（一段下跌，2026-09-23 §3j）**。**止跌 = 空头力量衰竭（最基本的价格行为，不用道氏）**：次日未新低（L 之后至少一根完成日线没跌破 L）或 止跌日长下影（`technical.detect_hammer`，canonical §四的量化口径）。**止损 = L = 下影线低点** | ⏳顶后新低（09-23 前名「⏳今日新低」）= 今日低点是 20 日顶之后的最低点且不是长下影（即将形成，明日不再新低即止跌）→ ✓止跌（已形成；只列信号 ≤10 根内的）；✗反弹结束 = 收破 L（从昨日框架判）；盘中破 L 收回 = 新框架 + `undercut_prev` 事实。随框架带出的事实（不是判据）：止跌日下影 % / 实体 % / 收盘位 / 量比、收盘是否站上止跌日最高点（canonical §七）、反弹幅度 / 反弹高 / 回踩低 | 止跌低 L = 止损；前高 = L 之前最后一个 5 根分形高（该段下跌最后一个 lower high）；反弹 vs 反转 = 两个事实：越前高（收盘 > 前高）/ 回踩更高低点（回踩低 > L 且其后一根未再破）→ 反转 = 两者皆有 / 反转候选 = 其一 / 反弹 = 皆无 |
| **🚀 趋势确认** `chart_read.trend_setup` | 现有 gate 转移机（`regime_transition`）：收盘站上卡片 `next_regime.entry_gate` ×N + RelVR≥1.1 → 转移 | ✓已转移（≤5 根内的上行转移）/ ✅站稳·量腿未过 / ⏳计数中 m/n / ▫️逼近（gate 之下 ≤1N）。**已形成 = ✓ ✅；即将形成 = ⏳ ▫️** | gate 线名 = `gate_path` 四分类（收复线 / 突破线 / 箱体顶 / 新高线，描述性） |
| 反弹 vs 反转 | `setups.bounce_or_reversal`（上一行的两个事实）+ 周线级先验（同一台周线道氏机：反弹先验 / 两级共振 / 大级别回调结束候选 —— 周线级判的是趋势，这正是道氏该待的地方） | 判读，不是退出指令（见 §4 D4） | |

为什么不用道氏判止跌（用户 第二裁，agent 同意）：道氏的 HH/HL 序列定义的是趋势翻面，四步机要等 HL+HH 完成才说话，那是「下跌结束」不是「卖压停止」；第一版拿它判止跌，等于用趋势工具答底部问题。V 形直拉没有阴线它永远停在①（STOCK_M 8/04、STOCK_E 8/24 起）也是同一个病。局部 20 日窗的代价照旧：窗滑过 L 后重锚，第 21 天读数可能跳变。
