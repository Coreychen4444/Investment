# 2026-08-18 入场委托 directive（用户 定，canonical）

> 语境：STOCK_GO270115C390000 LEAPS 平仓复盘（episode C，realized -$2,100：入场冲动单
> 3.1× cap + override 迟到 3 个交易日 ≈ -$725）。用户 当轮逐字：
>
> **「只有选股测我是 edge 入场侧应交由你来决定」**
> **「不接 机器挂单目前我仍觉得有风险 后续再说 依旧保留人工挂单」**
>
> 7/15 半年复盘的「入场信 用户 的读，退出信系统的钟」由 用户 本人收窄：
> 4/0 conviction reads 的 edge 只在**选股**（挑哪只票）；入场时点/价位/size 的临场
> 判断反复亏钱（STOCK_GO 8/5 冲动单、STOCK_W 8/12 财报夜追价、STOCK_Z 8/13 PLAN 在案不敢挂）。

## 分工四格（本 directive 定版）

| 格 | 归属 | 载体 |
|---|---|---|
| **选股** | 用户 的读 | 券商 App Watchlist 分组 membership（不变） |
| **入场决策**（进不进/几档/价位/股数/时点/取舍） | 系统 + agent | entry_guard 机械输出打底 → 简报 §4 **当日挂单清单** |
| **执行**（挂单） | 用户 的手，**永远人工** | 照清单执行，不加不改不追；想改 → 让系统改（重跑/重画），不是手上改 |
| **退出** | 系统的钟（不变） | exit_guard 栈；override「同刻挂单+无在途单点名」提议**已否，搁置再议** |

## 两个边界（2026-08-18 同轮 用户 裁决）

1. **多 PLAN 抢有限购买力 → agent 排序 + 理由，用户 终选**。清单按优先级排（结构
   新鲜度 / 距 z1 距离 / gate 档位等，理由一句话），用户 从中勾选要挂哪几张——
   保留一层人工选择权，但**选择域 = 清单内**。
2. **清单外 BUY → 必须先过 agent 一轮**：挂单前发一句（session/Telegram），agent 跑
   entry_guard + 卡片三数给 GO/NO，30 分钟内回。**等不及 = NO**。偏离（不问就挂）=
   规则外注解 + 执行率负样本（机械层 `price_flags` / `INFRA:fill_price_breach` 已接）。

## 修正案（directive 落地后追加）

### 2026-08-19 清单行时效边界 + 执行价取整（用户 裁）

1. **清单行时效边界 = z2 下沿**：某票现价跌破 z2 下沿后，该票**当日清单行自动作废**
   ——带内限价 BUY 此刻挂上去 = 立即按市价成交在破位区，单的语义已被价格反转。
   唯一合法动作 = 等收盘裁定（收回带内 → 明日照新清单 / 确认破位 → 重画换图）。
   机械出口 = heartbeat 告警 `z2_breach_buy_freeze`（🚫，两桶都查，只报 cap>0 卡，
   24h 边沿）。**冻结不动 cap**——授权改动的判据是收盘不是盘中快照（7/28 STOCK_O
   盘中永久降档事故），收盘后 postclose ≤10min 用真收盘裁定。
   源案例 = STOCK_Z 2026-08-18：盘中 134 < z2 下沿 139.4，清单/z1 备注/卡片全在用
   8/14 旧图说话，盘中零出口。
   反面明示：**盘中触带（未破带）照单挂 = 计划内**，`wl_zone_touch` 的设计意图
   就是邀请执行既有计划；晚挂好过不挂（8/15 教训）。
2. **执行价取整 ≠ 改价**：手动挂单可向**成交方向**取最近整数（sell 向下 / buy 向上），
   让价 ≤1%，buy 取整后不得越 no_chase。这是「确定交易下用最低成本提高成交率」，
   不算清单偏离、不注解、不进执行率负样本。画线/卡片/清单保持精确值，取整只发生在
   手上。源案例 = STOCK_Z 2026-08-18 trim 151.7 挂在 ⛔×13 拒绝墙上，高点 151.4 未成交。

## 不变项（明示，防过度发挥）

- **agent 不下单**红线不动（用户 同日：机器挂单有风险，后续再说）。
- 卖出/减仓侧本 directive 不辖——退出栈规则照旧（trend-exit-system）。
- v3 技术面优先（2026-08-04）不动：授权仍纯结构，本 directive 改的是**入场决策权
  的归属**（用户 → 系统+agent），不是授权判据本身。
- 「PLAN 在案没挂单 = 执行率负样本」（2026-08-15）继续成立，本 directive 是它的上位。

## 强制点

- 简报 §4 渲染合同：`tasks/claude/overnight-briefing.md` 第 8 步（当日挂单清单 = 排序 +
  取舍理由 + 每张单价位×股数）。
- 清单外 BUY 的机械出口：`INFRA:fill_price_breach`（2026-08-18 接线）+ 注解清单。
- 记分板：weekly review 的执行率统计把「照单率」纳入（清单挂了几张/偏离几笔）。
