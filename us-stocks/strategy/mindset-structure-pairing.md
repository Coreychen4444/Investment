# Mindset × Structure Pairing（心态×结构配对规则）

> 定位：框架层。判定一笔交易 / 一本 book 是否有"价值式持有"（不止盈、扛回撤、thesis 没坏不动）的**资格**。
> 资格由**结构**授予，不由 conviction 授予。2026-07-15 半年复盘定调（源案例见文末）。

## 核心命题

价值投资与趋势交易都是自洽的完整系统，各自的持有心态**只在自己的结构前提下成立**：

| 配对 | 持有心态 | 结构前提（全部满足才成立） |
|------|---------|------------|
| **价值配对** | 不止盈、扛深回撤、thesis 没坏不动 | 正股、零杠杆、无到期日、size 允许 -50% 不触发任何被迫动作 |
| **趋势配对** | 让利润奔跑，但退出无条件执行 | 杠杆/期权可用，退出权预先交给机械系统（exit 告警 = 当日执行或书面 override） |

**交叉配对 = 错配税**：价值的"不卖" × 趋势的杠杆结构 = 各取两流派的风险、各丢两流派的保护。
半年账户峰值回撤 -49.3%（同期 QQQ +3.7%）的真名是**错配税**，不是选股税（8/10 标的曾浮盈）。

## 判定规则（每笔 entry / 每次 hold 决策前）

1. **这笔是哪个配对？** vehicle 含期权或动用 margin → 自动趋势配对，无例外，入场时声明。
2. **趋势配对 book 上禁用的话术**："基本面没坏就拿着" / "长期 thesis 不怕短期波动"——margin book 资金久期 < thesis 久期，说这话没有资格（源案例：被强平标的 thesis 至今未证伪，仓位先死了）。
3. **价值配对的资格自检**：若该仓位 -50%，我会被迫做任何事吗（margin call / 到期日 / 心理崩溃卖底）？任一 Yes → 不是价值配对，退出纪律立即适用。
4. **研究边界**：研究给的是终点（EPS×PE 去哪），对路径（回撤深度 / 拥挤出清 / IV 坍缩 / 资金久期）零信息。**终点判断不得担保路径暴露**——用 thesis 强度为杠杆结构辩护 = 类别错误。
5. **敬畏市场的唯一可执行形式 = 清醒时预先交出的结构**（预挂止盈单 / 告警当日执行承诺 / 书面 override 流程）。欣快期里感受不到敬畏，情绪版敬畏不存在。接 [[bayesian-decision-model|Bayesian 决策模型]] 铁律 #5（pre-commit 防 decay）。

## 机制注脚（为什么不是"贪婪"）

道德词（贪婪）暗示意志力修复；意志力已实测失败（G-01 触发执行率 0/2，同错误六周两犯）。机制词才指向可工程化的修复：

- **实现厌恶**：平仓 = 宣判叙事结束，浮盈让"我看对了"永远悬而未决地活着
- **不对称后悔厌恶**：怕卖飞 > 怕回吐（解法 = 重进协议，见 [[trend-exit-system|赢家侧退出栈]]）
- **House money**：浮盈被当筹码不当资产 → 浮盈期 roll-up / 升 strike / 加新 LEAPS 前必答"下桌还是重新押上"
- **峰值锚定**：NAV 峰值成为"我的钱"，低于峰值卖出 = 亏 → 等回来

## 内证（同一账户、同一个 7 月、同一个人）

- **STOCK_Y 底仓**（价值配对：正股 + 锁死 + 无到期 + 无杠杆）：+149% 穿越 -49.3% 账户回撤全程存活——半年最佳决策。
- **STOCK_X LEAPS**（错配：价值心态 × margin+DTE 结构）：+100% 时 G-01 触发未执行 → 一个月后被券商风险等级强平 -$2,295——thesis 没输，结构先死。
- **两种配对都能活，只有交叉配对必死。**

## 与决策栈的关系

- 上游：[[bayesian-decision-model|Bayesian 决策模型]]（铁律 #5 pre-commit 是本规则的哲学基础）
- 并行：[[natural-humility-anchor|谦逊锚]]（深亏 hold 资格——同为"资格由结构授予"逻辑，方向相反的镜像）
- 下游：[[trend-exit-system|赢家侧退出栈]]（趋势配对的退出执行栈 + 机械化监控）
- 判据：exit 告警执行率（当日执行或书面 override 二选一的遵守率），月度 override ≥2 = 系统性问题
