# 内生市场论 — 短期波动的结构驱动模型

> **状态**：active · 建立 2026-06-08 · 源：《内生市场论》长文整合(篇 2)
> **定位**：回答"**为什么这个事件能在这个时点引发这么大波动**"。与 `macro-context-check.md` 机械层互补 —— 那层建模**"开枪"(机械出清/负 gamma 下杀)**,本文建模**"上膛"(共识溢价 + 拥挤累积)**。
> **优先级**：这是**理解层**(市场为什么这么动),不是信号层。它改变你怎么**解读**波动,不直接生成买卖。**短期幅度看结构,中长期方向仍回基本面(P=EPS×PE)** —— 见 §7 边界。

---

## 0. 主轴(一句话)

**不是事件让市场脆弱,而是市场先脆弱,事件才得以放大。** 新闻是火柴,干柴(仓位 / 杠杆 / 波动率结构 / 被动资金规则)早就堆好了。决定跌多深、涨多猛、何时反转的,是**共识多强、仓位多挤、边际买家是否枯竭、反向时多少资金被迫同步平仓**。

---

## 1. 反身性闭环(机制)

价格 → 波动 → 仓位 → 被动资金行为 → 反过来强化价格。

- **表层因果**：事件 → 下跌
- **真实因果**：`仓位拥挤 → 价格脆弱 → 事件 → 波动率↑ → 系统化去杠杆 → 相对价值仓位被迫平 → 价格加速`

→ 新闻只是**扳机**,枪早**上膛**。重排因果重要性:**仓位结构是主因,新闻是最方便被拿来讲故事的表层语言。**

---

## 2. 共识溢价(本文核心新概念)

**定义**:价格中被注入的"大家都相信它会继续正确"的信念成分。

- 逻辑**刚被接受** → 价格 = 基本面改善本身
- 逻辑**成为共识** → 价格 = 基本面 **+**(更多人会认同的预期 + 更多增量资金会进场的预期 + "这次不一样" + 系统性低估风险 + 对波动麻木钝化)

多出来的这一层 = **共识溢价**。

**铁律**:**共识越强 → 溢价越高 → 价格越依赖"共识必须继续维持"这个前提 → 前提一旦动摇(哪怕轻微)→ 反转越凶狠。** 反转打掉的不只是估值,是整层甚至几层"所有人都信它不会出问题"的心理 + 仓位附加值。

---

## 3. 拥挤诊断(6 信号 checklist)

拥挤 **≠** 持仓量,**≠** 很多人看好。拥挤 = **边际接盘能力不足下的同向风险暴露集中**。

**三问**:① 谁在持有(同质化资金 = 同条件同动作 = 脆弱)② 谁还没上车(**边际买家枯竭 = 真危险**)③ 大家会不会一起跑(同叙事 + 同风控 + 同模型 → 集体卖)。
+ 期权 / 杠杆 ETF / 融资可承载**远超现货规模**的方向暴露(现货股本没变,多头暴露已大很多)。
+ **拥挤 ≠ 看好**:若成本分散 / 周期不同 / 风格不同 / 还有大量潜在买家 → 未必拥挤。

| # | 信号 | 可计算? |
|---|---|---|
| 1 | 几乎所有人都在讲同一个故事 | 定性(需 sentiment) |
| 2 | 价格涨了很久,胜率叙事越来越自洽 | ✅ K线/return |
| 3 | 很多不同类型的资金挤同一边 | 定性(需 positioning) |
| 4 | 回调越来越浅(没人愿卖) | ✅ 量化 pullback 深度趋势 |
| 5 | 第一次跌破关键位 → 波动突然放大 | ✅ vol on break |
| 6 | **利好不怎么涨了,利空一来就疼** ← 最关键 | 半定性(需 event tag) |

**信号 6 = 边际买家已枯竭的最强证据。** 诚实边界:1/3/6 需 positioning/sentiment 数据(你无干净源)→ 人工判断;2/4/5 你的 `regime_score.py` + K线能算,但**核心两条(1/3)不可计算 → 不建假精确脚本**,checklist 人工跑。

---

## 4. 跌不动 > 利空很多(右尾风险)

CTA 在卖、vol control 在卖、人人利空、情绪差,**按理该一路崩**;但价格就是**跌不动 / 横住 / 缩量 / 局部反弹** → 该出的筹码出得差不多了,**边际卖压在衰减**。

此时继续追空:问题不是"方向对不对",是"**赔率好不好**"。再往下空间未必大,但一旦 vol 回落 + 被动卖盘结束 + 空头回补 → **右尾反抽又快又猛**。

→ 你是**结构性多头**,这条对你 = **别在 washout 底部 panic-sell + 机械砸点是 +EV 加仓**(见 §6)。

---

## 5. VIX 是变化速度,不是利空存量

VIX 反映**不确定性的 rate-of-change**,不是坏消息本身。地缘问题没真解决,只要市场**接受了新常态**,波动率也会掉。vol 一掉,前面被逼减仓 / 去风险的资金就可能回流 → **大跌后哪怕宏观没明显改善,也可能明显反弹**。

→ **价格先受结构驱动,叙事再来解释价格。** 市场先完成波动 / 仓位 / 风险预算再平衡,媒体才回头总结"为什么它涨了"。

## 7. 边界(§9 —— 不要把所有事件都当噪音)

强调内生驱动 **≠** 外部事件永远是表层噪音。**最大风险:过度迷信资金规律 → 低估那些真正改写未来现金流路径的事件。**

事件**直接改写定价分子 / 分母**(此时是**趋势性重估,不是错杀**)的情形:
- **战争**持续供应中断 → 改行业成本曲线 / 供需平衡 / 利润分配
- **政策**改税制 / 监管 / capex 约束 → 改企业长期盈利 + 估值锚
- **财报**揭示行业景气拐点 / 库存周期反转 / 需求永久弱化 → 全行业现金流预期下修
- **信用风险传染** → 资产负债表收缩 / 信用创造放缓 / 流动性偏好上升(系统性)

**判断口径**:**短期波动幅度 = 结构(仓位/拥挤/vol 传导);中长期趋势方向 = 基本面。** 别把趋势重估误判成错杀,别把真恶化误判成绝佳抄底。

**镜像 `feedback_dont_distort_for_comfort`**:那条防"把真涨说成 meme 安慰自己";本条防"把真跌说成踩踏骗自己抄底"。同一诚实纪律的两个方向。
